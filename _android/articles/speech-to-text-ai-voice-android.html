Platform SpeechRecognizer as a Flow

sealed interface SpeechEvent { data class Partial(val text: String) : SpeechEvent data class Final(val text: String) : SpeechEvent data class Error(val code: Int) : SpeechEvent } @RequiresPermission(Manifest.permission.RECORD_AUDIO) fun Context.listen(languageTag: String = Locale.getDefault().toLanguageTag()): Flow = callbackFlow { val recognizer = if (Build.VERSION.SDK_INT >= 31 && SpeechRecognizer.isOnDeviceRecognitionAvailable(this@listen)) SpeechRecognizer.createOnDeviceSpeechRecognizer(this@listen) // audio stays on device else SpeechRecognizer.createSpeechRecognizer(this@listen) recognizer.setRecognitionListener(object : RecognitionListener { override fun onPartialResults(b: Bundle) { b.getStringArrayList(SpeechRecognizer.RESULTS_RECOGNITION)?.firstOrNull()?.let { trySend(SpeechEvent.Partial(it)) } } override fun onResults(b: Bundle) { trySend(SpeechEvent.Final(b.getStringArrayList(SpeechRecognizer.RESULTS_RECOGNITION)?.firstOrNull().orEmpty())) close() } override fun onError(error: Int) { trySend(SpeechEvent.Error(error)); close() } override fun onReadyForSpeech(p: Bundle?) {} override fun onBeginningOfSpeech() {} override fun onRmsChanged(rms: Float) {} override fun onBufferReceived(b: ByteArray?) {} override fun onEndOfSpeech() {} override fun onEvent(t: Int, b: Bundle?) {} }) recognizer.startListening(Intent(RecognizerIntent.ACTION_RECOGNIZE_SPEECH).apply { putExtra(RecognizerIntent.EXTRA_LANGUAGE_MODEL, RecognizerIntent.LANGUAGE_MODEL_FREE_FORM) putExtra(RecognizerIntent.EXTRA_LANGUAGE, languageTag) // e.g. "hi-IN", "en-IN" putExtra(RecognizerIntent.EXTRA_PARTIAL_RESULTS, true) }) awaitClose { recognizer.destroy() } }.flowOn(Dispatchers.Main) // SpeechRecognizer must be used from the main thread

From transcript to action with AI

A transcript like "remind me to call the plumber tomorrow at 10" can be turned into a structured intent by a model, using structured output or function calling. See Function Calling.

@Serializable data class ReminderIntent(val title: String, val dateTimeIso: String?) suspend fun parseReminder(model: GenerativeModel, transcript: String, nowIso: String): ReminderIntent? { val response = model.generateContent( "Current time: $nowIso. Extract a reminder from the user's words as JSON with fields " + "title and dateTimeIso (ISO-8601, null if no time). User said: $transcript" ) return runCatching { Json { ignoreUnknownKeys = true }.decodeFromString(response.text.orEmpty()) }.getOrNull() } // Always show: "Create reminder 'Call the plumber' for tomorrow 10:00?" → user confirms.

Speaking responses: TextToSpeech

class Speaker(context: Context) : TextToSpeech.OnInitListener { private val tts = TextToSpeech(context, this) private var ready = false override fun onInit(status: Int) { ready = status == TextToSpeech.SUCCESS } fun say(text: String, locale: Locale = Locale.getDefault()) { if (!ready) return tts.language = locale tts.speak(text, TextToSpeech.QUEUE_FLUSH, null, "utt-${text.hashCode()}") } fun shutdown() = tts.shutdown() }

Permissions and privacy

  • Request RECORD_AUDIO in context, when the user taps the mic, and explain why.
  • Show a clear recording indicator, and stop listening when the user leaves the screen.
  • Prefer on-device recognition for sensitive content. Disclose any cloud processing and retention.
  • Never record in the background without explicit, ongoing user awareness.

Frequently asked questions

Does SpeechRecognizer support Indian languages?

Support depends on the recognition service and language packs on the device. Many devices support Hindi and other Indian languages. Test on target devices, and fall back to typing.

Can I transcribe long recordings?

SpeechRecognizer is designed for short utterances. For long recordings, record audio to a file and transcribe it with an on-device model or a cloud service.

Is audio sent to Google?

With on-device recognizers, audio is processed locally. Other recognition services or cloud APIs may send audio to servers, so check the service and disclose it to users.

Conclusion

Voice features combine speech-to-text (platform, on-device or cloud), optional AI interpretation into structured intents, confirmation before actions, and optional text-to-speech. Request the microphone in context, prefer on-device for privacy, and always keep a typing path.
