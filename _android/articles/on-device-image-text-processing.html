A camera pipeline

Text recognition from a photo

class TextScanner : AutoCloseable { private val recognizer = TextRecognition.getClient(TextRecognizerOptions.DEFAULT_OPTIONS) suspend fun scan(context: Context, uri: Uri): String { val image = InputImage.fromFilePath(context, uri) return recognizer.process(image).await().text // kotlinx-coroutines-play-services await() } override fun close() = recognizer.close() }

Language: ID, translation, entities

suspend fun translateToEnglish(text: String): String { val lang = LanguageIdentification.getClient().identifyLanguage(text).await() if (lang == "und" || lang == "en") return text val sourceLang = TranslateLanguage.fromLanguageTag(lang) ?: return text val translator = Translation.getClient( TranslatorOptions.Builder() .setSourceLanguage(sourceLang) .setTargetLanguage(TranslateLanguage.ENGLISH) .build() ) return translator.use { it.downloadModelIfNeeded(DownloadConditions.Builder().requireWifi().build()).await() it.translate(text).await() } } suspend fun findEntities(text: String): List { val extractor = EntityExtraction.getClient( EntityExtractorOptions.Builder(EntityExtractorOptions.ENGLISH).build() ) return extractor.use { it.downloadModelIfNeeded().await() it.annotate(text).await().flatMap { a -> a.entities.map { e -> "${e.type}: ${text.substring(a.start, a.end)}" } } } }

Best practices

  • Close detectors when done, and reuse clients during a session.
  • Downscale large images before processing to save time and memory.
  • Use confidence thresholds, and let users correct results.
  • Download language models over Wi-Fi with user-visible progress.

Frequently asked questions

Does ML Kit send images to Google?

The on-device APIs process data locally. Review each API's documentation and your Play Data safety disclosures.

How accurate is on-device translation?

It's good for getting the gist, but less fluent than cloud translation. Label it as automatic translation.

Conclusion

ML Kit gives you OCR, labeling, detection, translation and entity extraction on device: fast, private and free. Combine it with CameraX for live features, and add an LLM only when you need open-ended generation.
