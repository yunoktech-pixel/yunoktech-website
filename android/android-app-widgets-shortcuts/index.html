App Widgets and Shortcuts

Widgets put live information on the home screen, and shortcuts let users jump straight to key actions with a long-press. Both increase engagement without opening the app. Jetpack Glance lets you build widgets with a Compose-style API.

Widgets run inside the launcher process, not your app, so they use RemoteViews under the hood. Glance hides that complexity behind composable-style functions, but its components are separate from regular Compose UI, so not every Compose API works in a widget.

App shortcuts

Shortcuts appear on long-press of the launcher icon. Use static shortcuts (XML) for core actions, dynamic ones for context-dependent actions, and pinned ones that the user adds to the home screen.

Route shortcut intents through the same navigation as deep links.

Best practices

  • Design for multiple sizes, and use SizeMode.Responsive or SizeMode.Exact to adapt layouts.
  • Support dynamic colour with GlanceTheme.
  • Keep widgets glanceable: one purpose, a little key data, and a clear tap target.
  • Provide preview images or generated previews so the widget picker looks good.
  • Keep shortcut counts small (four or so are typically shown).

Troubleshooting

  • Widget shows "Can't load widget": an exception in provideGlance, or an unsupported composable. Check Logcat.
  • Widget not updating: call update/updateAll after data changes, and check that the work actually runs.
  • Clicks do nothing: use Glance actions (actionStartActivity, actionRunCallback), not Compose clickable lambdas.

Frequently asked questions

Can I use regular Compose in a widget?

No. Glance provides its own composables that map to RemoteViews. The programming model is similar, but the components differ.

Can widgets show lists?

Yes. Glance offers LazyColumn for widgets, backed by RemoteViews collections.

Conclusion

Use Glance for widgets with a Compose-like API, push updates when data changes (or with WorkManager), keep widgets glanceable and responsive, and add shortcuts for key actions routed through your navigation.
