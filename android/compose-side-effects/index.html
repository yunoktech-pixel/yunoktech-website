Side Effects in Compose: LaunchedEffect, SideEffect, and DisposableEffect

Composables should describe UI, not do work. But real screens must show snackbars, start animations, register listeners and log analytics. Compose's effect APIs let you run that work at the right moment, with automatic cleanup. Here's which one to use, and how keys control them.

A side effect is any change to the world outside a composable's own UI: a network call, an analytics event, a registered listener, a snackbar. Because composables may run many times, in any order, or be skipped, side effects in their bodies run unpredictably. The effect APIs give you control.

Real-world use cases

Load data for an ID

LaunchedEffect(id) { viewModel.load(id) }, or better, let the ViewModel load from SavedStateHandle in init.

Location or sensor updates

DisposableEffect, or lifecycle effects, to start on resume and stop on pause.

One-time onboarding hint

LaunchedEffect(Unit) to show it, plus persistence so it doesn't show again.

Common mistakes

  • Wrong keys: LaunchedEffect(Unit) when the effect depends on a changing ID, or keys that change every recomposition (new objects), which restarts constantly.
  • Forgetting onDispose cleanup, which leaks listeners.
  • Business logic in effects that belongs in the ViewModel.
  • Writing state in SideEffect, triggering endless recompositions.
  • Collecting flows in LaunchedEffect without lifecycle awareness. Use collectAsStateWithLifecycle or repeatOnLifecycle.

Frequently asked questions

Is LaunchedEffect(Unit) like onCreate?

Roughly, but per composition entry, not per Activity. It runs again if the composable leaves and re-enters composition.

Do effects survive configuration changes?

No. The Activity is recreated, so composition restarts and effects run again. Keep long-running work in the ViewModel.

Can I pass multiple keys?

Yes, for example LaunchedEffect(userId, filter). The effect restarts when any key changes.

Conclusion

Keep composable bodies pure and move work into the right effect: LaunchedEffect for suspend work tied to composition, rememberCoroutineScope for event-driven coroutines, DisposableEffect for register and cleanup, SideEffect for publishing state outward. Choose keys deliberately.
