🧪 Testing, Debugging, and Performance

Baseline Profiles and App Performance

Baseline Profiles tell Android which parts of your code are critical, so they're compiled ahead of time from the very first launch. They're one of the most effective performance improvements available, especially for Compose apps, and they take about an hour to set up.

On a fresh install, ART hasn't yet learned which code your app runs most. It interprets or JIT-compiles hot paths, so the first launches and first scrolls are slower than later ones. A Baseline Profile ships that knowledge with your app.

Choosing journeys

  • Startup, always.
  • The first screen's main interaction: scrolling the feed, opening search.
  • High-value flows where jank hurts: checkout, the player screen.

Keep journeys deterministic. Use test accounts or fake data so they don't depend on live content.

Libraries ship profiles too

Jetpack libraries such as Compose include their own Baseline Profile rules, which are merged into your app. Your profile adds your code paths on top.

Keeping profiles fresh

  • Regenerate when critical journeys or major code paths change, for example before each release.
  • Automate generation on CI with Gradle Managed Devices where feasible.
  • Track startup benchmarks over time to catch regressions.

Where they help most

Compose-heavy apps

Compose is a large library executed at startup. Profiles reduce first-frame and first-scroll cost.

Apps with frequent updates

Each update resets learned profiles on devices, and shipping a profile restores fast performance immediately.

Mid-range devices

The slower the device, the more noticeable the difference.

Frequently asked questions

Do Baseline Profiles work outside Google Play?

With the profileinstaller library, profiles can also be installed for sideloaded builds and other distribution channels, as described in the documentation.

Do they increase APK size?

Only slightly: the profile is a text-based list compiled into a compact binary format.

Baseline Profile vs startup profile?

Baseline Profiles guide AOT compilation. Startup profiles guide DEX layout so startup code is packed together. The plugin can generate both from the same journeys.

Conclusion

Baseline Profiles pre-compile your critical code paths so users get fast startup and smooth first interactions from the first launch. Generate them from deterministic journeys, commit them, verify the gain with Macrobenchmark, and regenerate as the app evolves.
