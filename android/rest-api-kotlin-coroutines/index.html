Common mistakes

  • Sequential calls for independent data, which doubles or triples loading time.
  • Retrying non-idempotent requests, such as creating a payment, without idempotency keys.
  • Retrying 4xx errors. Only transient failures (I/O, 5xx, 429 with backoff) deserve retries.
  • Parsing dates and enums without fallbacks.

Frequently asked questions

coroutineScope or supervisorScope?

coroutineScope fails fast when any child fails, which is right for required data. supervisorScope lets children fail independently. Above, the optional call handles its own failure instead.

Where do timeouts belong?

Set global timeouts on OkHttp, and use withTimeout for specific, latency-sensitive optional calls.

Should I return Result from repositories?

Either convention works. Pick one per codebase. This example throws and maps in the ViewModel.

Conclusion

Good API integration combines clean DTO-to-domain mapping, parallel calls for independent data, isolated optional failures, retries only for transient errors, and explicit UI states, all testable with fakes.
