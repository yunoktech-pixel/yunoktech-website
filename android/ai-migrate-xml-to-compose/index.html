AI-Assisted Migration from XML to Jetpack Compose

Converting XML layouts to Compose is repetitive work that AI does quickly, and subtly wrong if unsupervised. Combined with a disciplined migration process and screenshot tests, AI can cut the effort of moving to Compose substantially.

A typical XML screen involves a layout file, a Fragment with View Binding, a RecyclerView adapter, some custom styles and a few click listeners. Converting it to Compose is mostly mechanical, which suits AI, but behaviour hides in the details: focus handling, IME actions, accessibility, saved state.

Hosting during migration

Verifying equivalence

  • Screenshot tests of the old and new screens across states, dark mode and large fonts. See Screenshot Testing.
  • UI tests for interactions: clicks, retry, refresh, text input.
  • Accessibility checks with TalkBack: reading order and descriptions often change silently.
  • Performance on a release build: lazy lists with keys, no heavy work in item composables.

Prioritising screens

Start with

Leaf screens with simple state, such as settings and detail pages, to build team patterns.

Then

List screens with adapters, where Compose removes the most code.

Later

Complex custom Views and heavy animations. Wrap first, rewrite when valuable.

Frequently asked questions

Can AI convert a whole app at once?

It can generate a lot of code, but reviewing and verifying it all at once is impractical. Screen-by-screen migration with tests is far safer.

Should navigation move to Compose first?

Usually last. Migrate screens inside existing Fragments, then move navigation once most screens are composables.

Will the app size grow during migration?

Temporarily, since both UI systems ship. It typically improves once View-based dependencies are removed.

Conclusion

Let AI do the mechanical conversion of layouts and adapters into stateless composables, while you keep the ViewModel unchanged, host with ComposeView, and prove equivalence with screenshots, UI tests and accessibility checks, one screen at a time.
