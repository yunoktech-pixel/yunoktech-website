Build an AI Photo Caption Generator for Android

Pick a photo, choose a tone, get three caption ideas and accessible alt text. This project teaches multimodal prompting, image handling, structured output and responsible UX. Here's how to build it with Compose and Gemini.

Our AI Image Description guide covers describing images. This project builds a complete app around it: caption styles, structured multi-option output, an on-device path, and sharing.

App flow

1. Pick and downscale

Downscaling reduces upload time, tokens and cost, with little effect on caption quality. Use the photo picker for selection. See Privacy and Accessibility.

2. Ask for structured output

3. On-device alternative

On supported devices, ML Kit GenAI Image Description (beta) produces a short description with Gemini Nano, privately and offline. Use it for alt text and offer cloud captions as an option, or use hybrid inference. See Nano vs Cloud.

4. UI

Responsible design

  • Instruct the model not to identify people or infer sensitive traits (age, ethnicity, health).
  • Let users edit everything, and never auto-post.
  • Disclose that photos are sent to a cloud service, unless processing is on-device.
  • Handle safety blocks gracefully ("Couldn't caption this photo").
  • See Responsible AI UX.

Troubleshooting

  • JSON parse errors: use a response schema, ignoreUnknownKeys, and catch failures with a retry.
  • Slow uploads: downscale, and compress if you send bytes.
  • OOM on large photos: decode with a target size, as shown.

Frequently asked questions

Can it caption multiple photos?

Yes. Send several images in one request for a carousel caption, within the model's limits.

How do I keep costs low?

Downscale images, use a Flash-class model, cap output tokens, and rate-limit per user.

Conclusion

A caption generator combines the photo picker, downscaling, multimodal Gemini with structured JSON output, validation, and an editable UI, plus on-device alt text where available and clear responsible-AI choices.
