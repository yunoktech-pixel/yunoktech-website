Curriculum

    
What You'll Learn

    
Eight modules that take you from your first line of Kotlin to an app on the Play Store.

    

      
01
MODULE 01
Kotlin Fundamentals
  • Variables, types, null safety
  • Functions, lambdas & higher-order functions
  • Classes, data classes, sealed classes, enums
  • Collections & extension functions

      
02
MODULE 02
Jetpack Compose Basics
  • Composables, modifiers & previews
  • Rows, Columns, Box & LazyColumn
  • State, remember & recomposition
  • State hoisting & unidirectional data flow

      
03
MODULE 03
Material 3 & Beautiful UI
  • Theming, typography, dark mode, dynamic colour
  • Scaffold, TopAppBar, BottomSheet, Dialogs
  • Animations & transitions
  • Responsive layouts for phones & tablets

      
04
MODULE 04
Navigation & Architecture
  • Navigation Compose with type-safe routes
  • MVVM & Clean Architecture
  • ViewModel, UiState & events
  • Dependency injection with Hilt

      
05
MODULE 05
Coroutines & Flow
  • suspend functions, scopes & dispatchers
  • Flow, StateFlow & SharedFlow
  • Error handling & cancellation
  • collectAsStateWithLifecycle

      
06
MODULE 06
Networking & Data
  • REST APIs with Retrofit & Kotlinx Serialization
  • Room database & DataStore
  • Offline-first repository pattern
  • Image loading with Coil, Paging 3

      
07
MODULE 07
Firebase, Security & Testing
  • Firebase Auth, Firestore, FCM push notifications
  • Secure storage — lessons from banking apps
  • Unit tests, Compose UI tests
  • Crashlytics & performance

      
08
MODULE 08
Publish & Get Hired
  • Signing, App Bundles & Play Console
  • AdMob & in-app monetisation
  • GitHub portfolio & resume review
  • Mock interviews & common Android questions
